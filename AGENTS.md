# Repository guidance

When a user shares this repository and asks to set up Codex, Claude and Grok
collaboration, first read `subscription/CODEX_SETUP.md` and follow its guided
setup. The subscription-client workflow and the API example in the root
README are separate; do not silently switch between them. Preserve existing
instructions, services, credentials and in-flight tasks. Never request login
codes or secrets in chat. Do not treat setup or simulated tests as a successful
provider request. Follow the current user's instructions and actual permissions.

This guidance is for this repository's setup request. Do not silently install,
change a user's global rules, or start provider jobs merely because this file
was loaded.
